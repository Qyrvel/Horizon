### [E-means claims k-means speed with one-tenth the epochs](https://e-means.github.io/) ⭐️ 7.0/10

The E-means project page presents E-means as a faster k-means alternative that requires one-tenth the epochs, aimed at users running clustering over large datasets. The supplied material provides no independent validation of that claim; the evidence is the project page plus early user reports. One commenter said adapting the method to an IVF index produced a 146× GPU speedup, while another reported that it was not better for relaxing an icosahedral equal-area mesh on a sphere.

hackernews · porridgeraisin · Nov 9, 18:45 · [Discussion](https://news.ycombinator.com/item?id=50429734)

**「Background」** K-means is a standard unsupervised clustering method commonly implemented with Lloyd&\#x27;s algorithm, which iteratively assigns points to the nearest centroid and recomputes centroids until convergence. The E-means project page describes E-means as an open-sourced, modern, and robust k-means algorithm developed at Meta FAIR, and it benchmarks the method directly against Lloyd&\#x27;s k-means in epochs, CPU time, and GPU time.

**「What changes for practitioners」** For teams clustering large embedding sets, the paper reports that e-means reaches Lloyd k-means&\#x27; 25-epoch loss in 1.4–2.6 epochs, translating to 10–45× GPU wall-clock speedups versus state-of-the-art k-means implementations — the practical gain being fewer full passes over data rather than a different clustering objective. The method is built on mini-batch updates with an exponential moving average, so that advantage should not be assumed to transfer outside that setting: one commenter who adapted it for icosahedral mesh relaxation reported it was &quot;definitely not better&quot; for that use case. Practitioners should benchmark on their own data geometry before replacing Lloyd&\#x27;s algorithm.

**「Community Discussion」** Commenters treated the method as promising but use-case-dependent: one reported a 146× GPU speedup on an IVF index, while another said swapping it into a spherical mesh-relaxation project was “definitely not better.” A separate thread speculated that the update rule may correspond to expectation maximization with a friction term and noted that it keeps centroids within the convex hull.

### [Show HN: Watched Earth finds satellites over a place and their images](https://www.watched.earth/) ⭐️ 7.0/10

An open-source web tool, Watched Earth, lets users enter any place and see every satellite that passed over it in the last seven days, then view Sentinel-2, Landsat, and NASA imagery from those passes. The author reports that the browser-side SGP4 search over the CelesTrak catalog runs in about half a second, draws all ~17,000 objects on the GPU by solving Kepler&\#x27;s equation every frame, and was checked against brute force at the poles, the antimeridian, and tiny swaths with zero missed passes. According to the author, the tool labels a location &quot;watched&quot; only when a real image exists and does not store the user&\#x27;s location; the code is on GitHub. The author also noted that Sentinel-2 timestamps are often 5–10 minutes off from when the satellite actually crosses the selected spot.

hackernews · a585gupt · Nov 9, 17:51 · [Discussion](https://news.ycombinator.com/item?id=50428907)

**「How satellite pass prediction works」** Satellite pass prediction propagates a cataloged orbit forward in time; SGP4 is a standard model for doing that from publicly distributed orbital elements such as the CelesTrak catalog. Earth-observation images can then be matched to those passes using the acquisition time and ground footprint, with public missions such as Sentinel-2 and Landsat supplying archive imagery.

**「Impact」** For people checking imagery of a specific place, the tool ties pass predictions to actual Sentinel-2, Landsat, or NASA scenes rather than only orbital tracks, so a location is marked as watched only when a real image exists.

**「Community discussion」** Commenters largely praised the execution, with a geospatial professional saying the ability to see the exact image taken by a satellite makes it stand out from other satellite-overview sites. One user reported that typing in the location field was almost impossible because the cursor spacing was badly off, and another accused the post of being LLM-generated and questioned its feedback call to action.

The design warms masking from 40% to 80% over 300 steps and feeds magnetic, piezoresistive, and visuotactile sensors into one shared Transformer using canonical fingertip coordinates and 5D RoPE. ### [Twindex offers exact, replayable identifiability certificates for differential-equation fits](https://www.reddit.com/r/MachineLearning/comments/1xryhhg/twindex_exact_replayable_proofs_that_your_data/) ⭐️ 7.0/10

Twindex, announced in a self-posted Reddit project post, provides exact, replayable certificates for researchers fitting ODE, PDE and PINN models, showing when a data set cannot distinguish between parameter sets. The tool writes a small JSON certificate that a standard-library Python checker, using rational arithmetic rather than floats, replays as VALID, INVALID or INCONCLUSIVE under a stated bounded-noise assumption; a VALID twin pair implies no estimator can recover the parameter better than half the gap between the twins. In the author&\#x27;s 1978 boarding-school flu example, SIR models with R0 = 2.5 and R0 = 20 both fit the first five days of counts, and Twindex identified a next-day count that ultimately ruled out both. The project also offers full-prior pavings for upper bounds, a browser demo running locally via Pyodide at about 0.2 seconds per proof, and pip installation; the author acknowledges limited scaling beyond a few parameters, dependence on the model and noise bound, and no independent expert proof audit yet.

reddit · r/MachineLearning · /u/Longjumping\_Glass852 · Nov 9, 17:50

**「Why parameter identifiability is hard to settle」** Identifiability is the property governing whether model parameters can be uniquely inferred from data; when it fails, multiple parameter sets produce identical model output, a problem documented in epidemic models including SIR formulations with prior immunity and under-reporting. Twindex builds on established bounded-error estimation with validated integration, and its stated new contribution is packaging the result as a portable exact certificate that anyone can replay rather than as a point estimate from a fit.

**「What it changes for model fitters」** Practitioners fitting ODE, PDE, or PINN models get a local, exact check to run before publishing a parameter estimate: the JSON certificate plus the standard-library rational-arithmetic checker can flag a pair of parameter sets that fit the same data, which the author says replays in roughly 0.2 s per proof in-browser via Pyodide after \`pip install twindex\`. The bound it produces is only as strong as the bounded-noise assumption the user states, and the author notes that scaling beyond a few parameters is hard, so it works as an identifiability audit alongside — not a replacement for — statistical uncertainty quantification. The project is a self-posted announcement with no independent expert audit of the checker yet, so results should be treated as author-reported until the proofs are reproduced.
